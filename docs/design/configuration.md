# 設定ストアとセットアップ

[DESIGN.md](../../DESIGN.md#初期設定と公開中継の構築) の設定・`--setup`・既定アカウントの詳細。保存先と設定項目は [設定仕様](../configuration.md)、操作は [セットアップ手順](../setup.md) を参照する。VPS側の構築は [VPSインストーラー](section-03.md) を参照する。

## 設定ストア

設定ストアは環境変数、内部の明示パス、現在の利用者の既存 `~/dev/Secret/secrets.json`、利用者別の標準保存先の順にファイルを選ぶ。Windows・macOSのセットアップも同じ順序を使う。既存利用者の設定を維持しつつ、特定利用者の絶対パスに依存しないためである。MCPは起動時に選んだファイルを各呼出しで読み直し、消失・不正時に別ファイルへ切り替えない。

## `--setup`

`--setup`は専用Ed25519鍵の準備、設定ウィザード、通信を伴わないローカル確認を担当する。Windows・macOSともRust本体で対話入力を処理する。鍵と設定の保存先・本人所有を確認してOS別の利用者限定アクセス権を適用し、適用後にも検証する。所有者は変更せず、所有者の再設定に必要な権限を要求しない。保存先ごとにWindowsのMutexまたはmacOSのファイルロックで排他し、既存鍵・同名アカウント・共有中継設定は上書きせず、他の設定項目を保持し、保存直前に元の内容との一致を確認する。macOSでは本人所有・リンクでない保存先を検証し、ディレクトリ700・ファイル600を適用する。ホスト鍵指紋はVPS提供元のコンソールで照合した値を入力する。初期設定の完了やローカル確認は、SSH接続・Xログインの成功を意味しない。

## 既定アカウント

`default_account`は設定名を指すメタデータであり、アカウント一覧には含めない。`list_accounts`の`isDefault`は優先設定も含めた有効な省略先を示し、既定が不正でも一覧取得は許可する。セットアップは初回登録を既定に保存し、有効な既定は保持する。既定だけの変更では既存のアカウント・中継設定を維持し、認証入力や通信を要求しない。操作と詳細な優先順位は [設定](../configuration.md) を参照する。
