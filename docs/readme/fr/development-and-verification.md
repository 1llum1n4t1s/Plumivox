# Développement et vérification

Node.js n'est pas non plus nécessaire pour le développement, la compilation et les tests. Utilisez `cargo xtask build`, `cargo xtask check` et `cargo xtask test-e2e` de Rust/Cargo. Les enregistrements qui indiquent l'ancien lanceur Node doivent être modifiés pour utiliser le démarrage natif décrit ci-dessus.

Sous Windows, `cargo xtask build` met à jour `dist/plumivox.exe` après signature et vérification de la signature avec Sigilune (signature dans le cloud de Certum SimplySign). La CI de distribution signe elle aussi les artefacts Windows avec Sigilune avant de les enregistrer. Pour la configuration du poste de développement et les Secrets de la CI nécessaires à la signature, consultez les [artefacts de distribution](../../distribution.md#windows配布物のコード署名). Le Setup Windows est empaqueté avec `cargo xtask velopack-pack` et vérifié de façon isolée avec `cargo xtask test-setup-velopack-e2e`, sans toucher à une installation réelle. La distribution est effectuée uniquement par le job de distribution du Setup de `distribution.yml`, déclenché par un push d'un tag léger `v<version>` sur un commit de `main` ([distribution du Setup (Velopack)](../../distribution.md#setupvelopackの配信)).

Consultez la [procédure de compilation et de vérification pour les développeurs](../../verification.md), les [règles de travail](../../../AGENTS.md) et la [conception du système](../../../DESIGN.md).
